# DOCUMENTAÇÃO DO USO DA APLICAÇÃO

## Onde usar

- **Navegador:** acesse o site e entre com sua conta. O painel completo fica em `/dashboard`.
- **Computador do caixa (Windows, macOS e Linux):** instale o app desktop VyseSystem e entre com a mesma conta. Ele abre direto na tela de venda.
- **Celular:** use o app mobile para acompanhar o negócio de longe.

## App desktop

1. Entre com seu usuário e senha. A sessão fica salva no computador até você clicar em **Sair**.
2. Na busca, digite o código ou o nome do produto e tecle **Enter** para adicioná-lo à venda. Com um leitor de código de barras, basta ler o código do produto.
3. Escolha a forma de pagamento e clique em **Finalizar venda**. O estoque é atualizado na hora e a venda aparece no painel web.

Para deixar o computador dedicado ao caixa, abra o app com a opção `--kiosk`: ele ocupa a tela inteira.
