# VYSESYSTEM - WEB

Aplicação web do VYSESYSTEM, feito com Next.js e React.

## Rodando

Na raiz do monorepo:

```bash
npm install
npm run dev
```

## Organização

- `src/app/layout.tsx`: layout raiz (Stack)

Os tipos de domínio vêm de `@vysesystem/types`, os mesmos usados no app web.
